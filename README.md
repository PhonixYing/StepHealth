# StepHealth · 看懂每天的每一步

StepHealth 是一款简洁、重视隐私的每日计步 App。它把 Apple 健康里的活动数据，变成清晰、有温度的每日记录——没有复杂的训练计划，只有陪你走得更远的好习惯。

> 每一步，都算数，也都值得被看见。

## 下载

在 App Store 免费下载：

**[StepHealth – Step Counter](https://apps.apple.com/app/stephealth-step-counter/id6798724026)**

## 功能介绍

### 01 / 今日
步数、距离、活动热量和目标进度，一眼看懂今天走了多远。步数环和目标达成状态放在最重要的位置，每天打开都更有动力。

### 02 / 趋势
按周、按月回顾属于你的活动轨迹，让坚持看得见。保持节奏，感受自己一天天变得更好。

### 03 / 目标
不必紧绷着追赶别人。设定适合自己的目标，用温柔的小小鼓励，帮助你稳定地保持节奏。

### 04 / 趣味换算
让数字变得有画面感。用苹果热量、操场圈数等生活化的语言，理解每一次出发有多厉害。

### StepHealth Pro（终身版）
一次解锁，终身使用：

- 年度与完整历史趋势
- 周报、月报与数据导出
- 多个目标计划与提醒
- 专属小组件与主题

## 隐私

你的健康数据，不该成为商品。

- StepHealth 通过 Apple 健康读取活动记录，数据主要在你的设备上处理
- 不售卖健康数据，不做广告追踪
- 不需要注册账号
